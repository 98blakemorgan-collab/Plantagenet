1. (Optional tidy) Rename or remove any old TLM_R11_FLASHY_Show_Files
   folder. Since the R13.1 package, no cue carries an R11 alias any more,
   so QLab cannot pick it up by mistake.
2. Put this folder, named exactly TLM_R13_REBUILT_Show_Files, on the
   Desktop, and open TLM_Show_R13_1.qlab5.
   Check: no missing-media warnings; select Q4's audio and confirm the
   target ends in _v2.wav. If any audio cue shows as missing, drag the
   file named in R13_1_SFX_RETARGET_MAP.csv onto it. Then File > Save.
3. QLab Workspace Settings (these are specific to the show Mac):
     Audio   Patch 1 -> StudioLive USB device (NOT System Output)
     Video   Stage 1 -> projector output (NOT built-in display)
     Network MANTRA -> interface = wired Ethernet
4. Mantra: Home > Tools > Import Show > TLM_SHOW_2026_R13_FLASHY_SCENE_SPLIT.mtr
   Network: Art-Net and sACN are both on - turn off the one the U2 node
   doesn't use.
5. Test P2 M10 SAFE LIGHT, then a cue-to-cue.
